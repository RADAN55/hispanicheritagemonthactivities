# hhactivities

Student activity packet for the Hispanic Heritage 30 People gallery — ten activities, 22 pages,
grades 9–12 English learners.

## Setup

1. Create a public repo named `hhactivities`.
2. Upload `index.html`, `activities.pdf` and `.nojekyll`. Commit to `main`.
3. Settings → Pages → branch `main`, folder `/ (root)`.
4. Open **radan55.github.io/hhactivities/**

The page shows the PDF inline with download and open-in-tab buttons, and links back to the
gallery. Replace `activities.pdf` with a new version and the page updates on its own — keep
the filename.
